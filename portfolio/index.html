접근 & 과정
  • 실측 기반 모델 평가 엔진 — 학습 시점에 고정된 더미 지표를 걷어내고, 대시보드에서 고른 모델×데이터셋으로 Macro-F1·클래스별 성능·13×13 혼동행렬을 즉석 계산하도록 설계. 미탐(FN, 1,700만원/건)과 오탐(FP)의 비대칭 비용을 반영한 기대비용 임계값 곡선을 구현해 "이 임계값을 운영에 써도 되는가"에 수치로 답하게 했습니다.
  • 검증 기반 파생피처 브리지 — 실시간 입력은 원본 행뿐인데 모델은 81개 파생피처를 요구했습니다. 변환 규칙을 역학습하되 홀드아웃 일치율 98.5% 이상인 전략만 채택하고 근사분은 리포트에 명시해, leakage 없이 "검증되지 않으면 쓰지 않는다"를 코드로 강제했습니다.
  • 합성 데이터·배치 분석 — train 분포를 학습한 합성 데이터 생성기와, 유형별 집계·상위 위험거래를 자동 요약하는 배치 분석 모듈을 개발했습니다.
  • 운영 시스템 — 4개 언어 i18n·7개 테마 대시보드에 RAG(한국어 SBERT) + 3단계 LLM 호출 + n8n 실시간 알림을 연결해 "왜 이상거래인지 + 권장 조치"를 자동 생성합니다.
데이터 거버넌스 · 방어적 설계
LLM·Slack·이메일로 나가는 모든 데이터에 5단계 PII 마스킹을 강제하고, 전 모듈에 폴백·에러 바운더리를 두어 일부 실패에도 시스템이 중단되지 않도록 격리했습니다.
배운 점
성능 숫자보다 "그 숫자가 진짜인가(평가의 독립성)"와 "이 자동화가 안전한가(마스킹·환각 통제)"를 증명하는 과정이 실무에서 더 중요하다는 것을 체감했습니다.
멘토 평가 — "방법론·실무성·완성도를 가장 높은 수준으로 결합한 팀. 데이터 품질 이슈를 오류와 정보로 가려낸 판단, 비용 비대칭으로 임계값을 정한 것 — 하나하나가 실전에 근접해 있다."

팀 참여 · 미래 날짜·음수 시간차 등 품질 이슈를 "오류 vs 정보"로 판별, 그룹 누수 41%를 정량화해 StratifiedGroupKFold로 통제(누수 0건).

  • 무프레임워크 구현 — 외부 차트 라이브러리 없이 Canvas·SVG로 레이더·파이·지역 맵을 직접 그리고, 5개 세션을 클릭·호버로 연동했습니다. 3개 언어 i18n과 Web Speech 기반 TTS 나레이션(음성·속도·음량 조절)도 구현했습니다.
배포 견고성

배운 점
분석은 "차트를 만드는 것"이 아니라 "보는 사람의 관점에서 의사결정으로 번역하는 것"임을 배웠습니다. 같은 로그도 임원과 유저에게는 완전히 다른 화면이어야 합니다.
튜터 평가 — "문제정의 → 뉴비 정의 보정 → 모델링 → 4관점 해석 → 대시보드 액션으로 이어지는 서사 연결이 가장 매끄럽고, 기획·스토리텔링이 최상위."

접근 & 과정
  • 9종 모델 교차 평가 — KNN·Random Forest·XGBoost·HistGB 등 9종을 비교한 결과, 트리 앙상블이 모두 75%대에서 정체했습니다. 선형 계열(LR·SVC·NB)은 데이터의 비선형성을 풀지 못했습니다.
  • 한계의 원인 규명 — 혼동행렬을 보면 정상·Rich는 오답률 0%에 가깝게 분류되지만, 가장 성능이 좋은 모델조차 Fault 2(Lean)와 Fault 3(Low Voltage)를 약 50% 확률로만 구분했습니다. 더 좋은 모델의 문제가 아니라 데이터가 두 결함을 분리할 신호를 담고 있지 않다는 결론이었습니다.
  • 파생변수 실험의 정직한 검증 — MAP→kPa 변환, RPM 구간별 TPS 분산 등을 추가했으나 성능이 개선되지 않음을 확인하고, 그 이유(선형 스케일 변환이라 트리 모델의 분기 순서가 유지됨 등)까지 해석했습니다.
  • 도메인 기반 이상치 처리 — 이상치를 일괄 제거하지 않고 "명백한 고장의 증거"와 "극한 운전 조건"으로 나눠 판단해 실제 결함 신호를 보존했습니다.
결과 — 데이터 한계를 전략으로 전환
구분 불가능한 두 결함군을 ISO 26262 HARA/ASIL 등급 근거로 통합 정당화하고, 3-Class로 재설계해 전 모델을 ASIL D 수준(99%대)으로 끌어올렸습니다. 이어 COPQ 절감·예지보전 전환·MAF 센서 추가라는 실무 액션까지 연결했습니다.
배운 점
"성능이 안 나오는 이유를 데이터에서 증명하는 것"도 훌륭한 분석 결과입니다. 모델을 더 돌리는 대신 문제를 재정의하는 판단이 더 큰 성과로 이어졌습니다.
튜터 평가 — "9종 모델이 모두 75%에서 멈춘다는 결과로 '모델이 아닌 데이터의 한계'를 입증한 점이 우수. 자동차 OEM 품질 부서에 제출해도 손색없는 출발점."

  • 가설 검증형 시각화 — BMI 구간별로 나누자 흡연자의 헤모글로빈이 모든 구간에서 평균 1.28 g/dL 높게 나타나 혈액 농축 경향이 드러났고, 간 효소는 γ-GTP가 +22 U/L로 가장 크게 반응했습니다.
  • 복합 효과 발견 — 흡연과 고BMI가 결합하면 γ-GTP 격차가 최대 28.7 IU/L(약 62%)까지 벌어져, "고BMI 흡연자"라는 우선 개입 타겟의 근거가 되었습니다.
  • 교란변수 포착 — 60대 이후 흡연·비흡연 혈압이 역전되는 현상을 시각화 과정에서 발견하고, 연령대별 고혈압 비율 그래프로 연령이 강한 교란변수임을 입증해 대안적 해석을 제시했습니다.
데이터 품질 검증
IQR을 그대로 적용하면 실제 질병 수치(고위험군)까지 잘려나가므로, 의료 임계값 기반 전처리로 바꿔 왜곡을 방지했습니다(38,984 → 38,740건, 제거 244건).
